## 如何贡献

我们欢迎各种形式的贡献：

**详细的贡献指南，包括分支规则和 PR 流程，请参阅[贡献指南](./guide/contributing.html)。**

### 报告问题

发现 bug、有功能请求或想讨论想法？[打开一个 issue](https://github.com/bradygaster/squad/issues)。

### 提交拉取请求

准备贡献代码？[查看开放的 issues](https://github.com/bradygaster/squad/issues) 并提交 PR。分支保护规则和分支模型请参阅[贡献指南](./guide/contributing.html)。

### 加入讨论

有问题、想分享你如何使用 Squad，或讨论路线图？[开始讨论](https://github.com/bradygaster/squad/discussions)。

### 外部部署和案例研究

在你的项目上部署 Squad 并分享你的经验。这些真实世界的部署为我们的路线图提供信息，并帮助社区相互学习。
